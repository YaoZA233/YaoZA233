## 🌸 关于我

你好，我是 **ZhongHUi.**。

一个喜欢探索技术、折腾开源软件，也对生活保持好奇的人。

我的技术探索始于大学。

大一时，我加入了学校的 **RoboMaster 和 RoboCon 实验室**，成为视觉组的一员。在那段时间里，我接触了 OpenCV、YOLO、机器人视觉和目标检测，也参与了机器人相关的技术学习与实践。

后来，大二时我选择退伍，也因此结束了实验室的视觉方向探索。

虽然这段经历没有一直延续下去，但它依然是我大学生活中很重要的一部分。

**现在的我，仍然在寻找感兴趣的技术方向：**

- 🐧 使用 Arch Linux，探索 Linux 和开源生态。
- 💻 学习 Python、C++、Dart 等编程技术。
- 🌐 折腾个人博客、Cloudflare 和 Web 部署。
- 🤖 对机器人、自动化和计算机技术依然保持兴趣。
- 🌸 喜欢动漫、音乐，以及日常生活中的小美好。
